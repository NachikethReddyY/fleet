# Thread-analysis report contract

Write one Markdown file at `.analy/thread-analysis/<UTC-timestamp>-<slug>.md`. This is a retrospective index, not a transcript. Use message, artifact, or verification pointers for detail.

```md
# Thread analysis: <short title>

- Thread: <current conversation, stable URL if available>
- Invoked: <UTC timestamp>
- Scope: <what the thread attempted>
- Outcome: <completed, partial, blocked, or failed>

## Brief

<short account of the goal, path taken, and result>

## Good points

- <observable practice to continue; pointer or evidence>

## Mistakes and misses

- <observable miss; impact; correction or open question>

## Continue this round

- <practice worth keeping while the work remains active>

## Next round

1. <prioritized recommendation, reason, and expected proof>

## Decisions and blockers

- <accepted decision, unresolved decision, or concrete blocker>

## Verification

- <checks, user-visible observations, and evidence pointers>
```

Keep strengths and misses evidence-backed. If a category has no material finding, say so instead of inventing one. Recommendations may be handed to another AI, but the report itself never applies them.

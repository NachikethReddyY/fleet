# Command Center

Use remote machines such as BB1 for heavier work when local resources should stay free.

## Guidelines

- Prefer remote execution for long-running or resource-heavy tasks.
- Keep local system responsive by offloading suitable work.
- Document how to reach each remote machine before using it.
- Treat CLI proxy as deprecated unless explicitly requested.

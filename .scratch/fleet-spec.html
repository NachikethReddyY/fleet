Fleet Spec

Dense implementation notes. Mobile readable. No fixed widths.

Scope Model

  • Canonical source is under skills/<bucket>/<skill>/SKILL.md.
  • universal skills sync to every provider root.
  • command-center is an additional provider-agnostic bucket.
  • Provider buckets sync only to their matching root: claude, codex, opencode, gemini, copilot, and pi.
  • Legacy flat skills at skills/<name> remain compatible.
  • .agents/skills stays Fleet-local and is never synced globally.
  • One authoritative home per rule; copies must be symlinks or generated.

Sync And Health

  • scripts/sync-agent-configs.sh links universal and provider-scoped skills to each provider root.
  • Provider root symlinks are not expanded into scoped links.
  • scripts/check-symlink-health.sh validates scoped links and reports stale, broken, wrong, missing, and leaked links.
  • Stale Fleet links are reported, not silently pruned.
  • Foreign skills are ignored.
  • Non-symlink existing files are refused, not overwritten.

Skill Usage

  • Skill ID is the directory basename.
  • Universal skills reach every agent.
  • Provider buckets reach only the named harness.
  • file-pr handles PR review, filing, and updates.
  • file-pr can delegate attachments through file-upload.
  • pr-comments owns the attribution callout for agent-authored replies.
  • take-over preserves credit and verifies work before reporting.

File Upload

  • Use GitHub's built-in attachments before building separate storage.
  • Images use PNG, JPEG, or WebP with alt text.
  • Videos use MP4, MOV, or WebM and should be tagged as screen recordings.
  • Inline previews help; create a short GIF preview for clips under about 30 seconds.
  • Example GIF command: ffmpeg -i input.mp4 -vf "fps=10,scale=720:-2:flags=lanczos" -loop 0 preview.gif.
  • Embed the GIF and link the high-quality video beneath it.
  • Maximum 50 uploads per command.
  • Maximum 10MB images/GIFs, 25MB most other files, video limits vary by plan.
  • Private and internal repo uploads are visible only to authorized users.
    • Do not upload secrets, credentials, or sensitive logs. For unsupported or too-large files, commit to the repo or use approved external storage.

Attachment Placement

  • Multiple screenshots are attached with repeated --attach flags.
  • Place images in the PR body by referencing the local path, then attach it.
  • Example body text: ![Before](before.png).
  • Example command: gh pr create --body-file pr-body.md --attach ./before.png --attach ./after.png.
  • The CLI rewrites local references to uploaded asset URLs.

Media Choice

  • PNG for screenshots requiring sharp text and UI.
  • WebP for smaller screenshots.
  • Short GIF previews for inline motion context.
  • MP4 or WebM for higher-quality recordings.
  • MOV only when source compatibility requires it.
  • Keep previews under roughly 30 seconds.

Verification

  • sh tests/check-symlink-health.test.sh
  • python3 -m unittest discover -s tests -p 'test_*.py'
  • python3 scripts/check-skill-references.py
  • bash scripts/check-symlink-health.sh in the real environment.

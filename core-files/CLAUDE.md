# Agents

## Commit messages

Conventional Commits format: `type(scope): description`

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `perf`, `ci`, `chore`, `style`, `build`, `revert`.

Breaking changes: add `!` after the type or add `BREAKING CHANGE:` in the footer.

Wrap body lines at 72 characters. Link issues with `Closes #N`, `Fixes #N`, or `Refs #N`. Use `Co-authored-by: Name <email>` when applicable.

## Attribution

Never use the default "🤖 Generated with Claude Code" footer or any Claude Code attribution line. These rules replace it.

- **Commits:** end the message with the trailer `Co-Authored-By: Claude Haiku 5.5` (no email address). Use the name of the model that wrote the change.
- **PR descriptions:** use the format in the `file-pr` skill: `Generated by [model name] through [harness name].` Add it only when an agent wrote the text or the change. Do not add it to a human-authored PR.
- **PR and review comments:** use the callout in the `pr-comments` skill: `> [!NOTE]` followed by `> 🤖 **[ModelName] is responding on behalf of Nachiketh**`.
- **No attribution:** when the user says "no attribution", omit every attribution line above from that commit, PR, or comment, and do not add a substitute.

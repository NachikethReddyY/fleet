# Agents

## Commit messages

Conventional Commits format: `type(scope): description`

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `perf`, `ci`, `chore`, `style`, `build`, `revert`.

Breaking changes: add `!` after the type or add `BREAKING CHANGE:` in the footer.

Wrap body lines at 72 characters. Link issues with `Closes #N`, `Fixes #N`, or `Refs #N`. Use `Co-authored-by: Name <email>` when applicable.
